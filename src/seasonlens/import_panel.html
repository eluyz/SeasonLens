Excel .xlsx or UTF-8 CSV, maximum 12 MiB and 20,000 data rows per instrument. Old .xls and macro-enabled .xlsm files are unsupported. Valid observations after the cutoff are counted and excluded; malformed rows still reject.

Workbook rows

Row numbers are physical worksheet rows. The default first data row is 4, so row 3 can contain your live quote. Excel numeric dates use the workbook's date system; text dates use the explicit format above.

CSV series

CSV supports one series per file, a header on the first row, ISO YYYY-MM-DD dates and explicit column names. Use Excel for a master file with several instruments.

Physical row preview

Choose instruments from price columns

Select each column to import and declare its title, units and role. No commodity or currency identity is guessed from a column name. Same-workbook EUR/PLN rates can support exact-date PLN views; sample FX is never substituted.

Invalid dates, duplicate dates, wrong decimal separators, nonfinite numbers and cell errors reject the whole selection. Thousands separators are unsupported. Values must be zero or have magnitude between 1e-100 and 1e100. Missing prices are skipped only if you permit it. Formula results are never recalculated.

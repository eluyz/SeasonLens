Start here — explore, import or create a report

Choose a path. The six built-in instruments use SYNTHETIC, invented data to demonstrate the analyses; they are not live market quotes.

1. Explore the examples

Use Analysis options to choose an instrument and display units. Start with the five-year monthly chart, then compare the monthly table. The analysis cutoff tells you which observations are included.

2. Import your own history

Open an XLSX workbook or CSV, choose the cutoff and columns, then Validate. Review the result before choosing Add validated instruments to this tab. Opening a file alone does not add it.

Your file and imported prices stay in this browser tab. Reloading clears private imports. Export a report or observations to your device before leaving.

Open private import

The template download is available when this build includes the workbook.

To try the invented template: select Prices, header row 1, first data row 4, date column A and cutoff 2026-10-06. Row 3 is an invented live example and must stay excluded. Declare the units and roles explicitly using the workbook's Read me sheet. Replace the examples with your own history when ready.

3. Create a report

Select the instrument, units and analysis settings first. In Export report, choose sections and build a preview. The preview is a fixed snapshot; rebuild it after changing the analysis.

Download HTML saves a standalone report with charts. Print / Save PDF uses your browser's print dialog; choose Save as PDF if your browser offers it. Reports contain selected results, not the original observation arrays. Sharing a downloaded report shares its visible results.

Open report builder

Tables and charts can scroll sideways independently. On a keyboard, focus their frame and use the arrow keys. A dash means unavailable data; it does not mean zero.

# Statistical analysis extension — implementation contract

Scope: browser-side descriptive historical risk, completed-year return seasonality and stability, exact-interval commodity/FX variance attribution, honest fixed-model walk-forward forecast comparison, and a separate private fundamental-data panel. No trade execution, investment-return claim, causal attribution, official-source impersonation, network requests or private storage. Built-in examples remain six synthetic instruments. English UI/docs. Existing calculators and SQLite/import behavior stay intact.

## Shared inputs and runtime

New inline JS modules load after market_ui.js and before scientific_ui.js. Globals: SeasonLensScienceCommon, SeasonLensRisk, SeasonLensSeasonalStats, SeasonLensForecasts, SeasonLensFundamentals. Pure functions accept arrays of {date: ISO YYYY-MM-DD, value: finite number} plus explicit asOf. Validate ALL original rows before cutoff, reject duplicate/impossible dates, non-real numbers and invalid numeric limits; never mutate/fill/sort caller data in place. Valid numbers are zero or absolute magnitude in [1e-100,1e100], consistent with existing import. Sort an independent copy. No implicit today. Zero/negative endpoints make positive-price changes unavailable and are explicitly counted. Empty cutoff-visible results are legitimate missing states. Use numerically safe mean/sample covariance/RMSE or reject arithmetic overflow clearly. Pure modules support Node require and browser globals, no dependencies, network, DOM or storage.

SeasonLensScienceCommon exports validateRows(rows,asOf), mean(values), quantile(values,p), sampleCovariance(a,b), monthShift(date,months), finiteNumber(value), and pctChange(current,previous). validateRows returns a cutoff-visible sorted independent array after validating the entire input. mean([]) and unavailable statistics return null. quantile uses linear interpolation unless the risk-specific empirical quantile explicitly says otherwise. sampleCovariance uses ddof1 and returns null with fewer than two observations.

UI initialization: initSeasonLensScience({data,view,marketRows,marketFXId,cutoff:()=>cutoff,chart:marketChart,esc,fmt:marketFmt,card:marketCard}). It returns an object with refresh(), idempotent installation and bounded per-view caching. Root calls refresh whenever existing refresh()/range changes occur. No private preferences persisted. Risk/FX/forecast default analysis period last five calendar years, optional one year/all history. All computations use explicit selected cutoff. Seasonal window separately 5/10/all completed available calendar years. Synthetic vs private provenance remains visible. Modules must work for imported XLSX/CSV and selected exact-date PLN/t views.

## Historical risk

SeasonLensRisk.historicalRisk(rows,{asOf,horizon:1|5|20,confidence:.95|.99,direction:'buyer'|'seller'}) returns counts, omission details, empirical loss quantile, exact fractional-tail expected shortfall, mean/median change and histogram/interval rows. Horizon means consecutive OBSERVED intervals, not guaranteed calendar/trading days. Percentage change=(end/start-1)*100; buyer loss=change, seller loss=-change. For n ascending losses empirical VaR index=ceil(confidence*n)-1. ES integrates the upper (1-confidence)*n observations with fractional boundary weight, not merely losses strictly above VaR. Preserve negative loss estimates, do not clamp. Require tail mass >=5 (n>=100 at95%; n>=500 at99%) before displaying VaR/ES; return explicit unavailable reason below threshold. Report overlapping horizon dependence and excluded nonpositive-endpoint intervals. Exposure cost is current selected quote × quantity × signed loss/100, an arithmetic current-budget scenario, not a futures holding P&L.

SeasonLensRisk.stressEpisodes(rows,{asOf,horizon}) returns largest observed rises/falls and maximum peak-to-trough decline / trough-to-peak rise with endpoint dates and observed interval duration. Nonpositive levels break ratio paths. No imputation or investable drawdown claim.

SeasonLensRisk.fxRisk(commodityRows,fxRows,{asOf}) matches log returns on EXACT start AND end dates from each original sequence, not returns recomputed on an inner-joined grid. Use sample variance and covariance in percentage-log-return units (logs times100): totalVar=varCommodity+varFX+2*cov. Euler contributions=varCommodity+cov and varFX+cov. Shares divide by totalVar; zero total variance means undefined shares, not50/50. Negative/>100% shares are meaningful and never clamped. Return source/paired interval counts and dates. UI permits ONLY marketFXId selected original EUR/t commodity's explicitly compatible original EUR/PLN; no synthetic/private or private-group mixing.

## Completed-year seasonality and uncertainty

SeasonLensSeasonalStats.analyze(rows,{asOf,windowYears:5|10|'all',bootstrapReplicates:1000,seed:fixed}) returns declared completed-year bounds, month summaries, yearly return grid, early/late calendar split, leave-one-year-out mean ranges and approximate block-bootstrap95% mean intervals when data is sufficient. Monthly change=actual last observed quote this month / actual last observed quote IMMEDIATELY previous calendar month minus1, available only when both actual closes are positive. A missing calendar month breaks return; zero/negative actual month close is unavailable, never replace with an earlier positive quote. Exclude current calendar YEAR from all baseline metrics; use preceding December to establish January if available. Each year contributes one monthly change with equal weight. Show contributing years, not daily-row sample size. Positive fraction excludes zero as positive but keeps it in denominator. Calendar split is fixed by declared window midpoint, not shifted to fill gaps. Leave-one-year-out unavailable with <2 contributors. Bootstrap resamples contiguous two-year blocks of the declared complete-year vector (all12 month columns together, retain missingness), reproducible seeded RNG; maximum1000/2000 iterations and window<=100 years. Require >=8 valid yearly observations per month and >=90% valid replicates; otherwise no interval. Explicitly label interval of historical mean, approximate assumptions, small-sample/recent-regime limitations, not a forecast interval or significance verdict. No independent daily bootstrap, p-value shopping or trading advice.

## Forecast lab

SeasonLensForecasts.evaluate(rows,{asOf,horizons:[1,5,20],minTraining:200,maxOrigins:252}) compares fixed naive last price, expanding-history drift and trailing20 mean on identical eligible rolling origins. Train only rows at/before origin; actual target strictly later in observed-index time, through cutoff. Show MAE/RMSE in selected units, sample count, first/last origin and target, errors by horizon and skill vs naive; no best-model profitability or automatic tuning. Limit computational cost, handle unavailable short data/numerical range without whole-dashboard failure. Use original full cutoff-visible history for warmup, restrict EVALUATION target/origin period per UI declared analysis range; optional startDate parameter must be explicit and not leak future data. Latest model forecasts optional but must be clearly hypothetical observed-step horizons without guessed session dates; a comparison-only first version is acceptable.

## Fundamental context

SeasonLensFundamentals is independent from price series, no automatic role/market joins. Private CSV import and invented demonstration only until an actual public-source adapter/redistribution has been validated. Normalized schema at minimum publication_date, commodity, region, marketing_year, unit, ending_stocks, total_use; finite positive total_use, nonnegative stocks, explicit declared price-commodity/region mapping and units. Stock-to-use=100*ending_stocks/total_use. Validate all rows before cutoff, duplicates by publication_date/commodity/region/marketing_year reject, never use future publication rows. Show publication date, marketing year, geography, units, ratio and revisions to same marketing-year estimate if available; release timing must remain visible. Reject ambiguous header/source claims. Official USDA WASDE links/instructions may be included with exact verified URLs; private normalized imports labelled USER_FILE, not USDA. Raw official-format adapter if feasible must be explicitly tested against authoritative schema, retain release/vintage and avoid latest revisions leaking into historical tests. No need to pretend rapeseed detail exists in generic oilseed totals. Never label synthetic fundamental observations as official. Actual external dataset collection is a later operational step if transport/schema isn't available; ship useful private schema import without fabricated source claims.

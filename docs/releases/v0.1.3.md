# SeasonLens 0.1.3

Experimental release for inspecting changes between two XLSX master-file versions before an import.

Use the [live app](https://eluyz.github.io/SeasonLens/) in English or Polish, or extract the complete frozen browser ZIP. Start with the [invented-data walkthrough](https://eluyz.github.io/SeasonLens/walkthrough.html), then follow [workbook comparison](https://github.com/eluyz/SeasonLens/blob/v0.1.3/docs/GETTING_STARTED.md#compare-two-xlsx-versions). No account is needed.

## Changes

- Open the newer XLSX, configure it manually or with an existing local profile, then optionally select an older XLSX for a read-only comparison. Exact selected worksheet and date/value header identities are required.
- Apply the same current mapping, declared units/roles, parsing conventions, cutoff and explicit blank/formula permissions to strict validation of both workbooks. Invalid selected records in either file reject, including malformed or duplicate future rows.
- Show per-instrument older/newer observation counts and date ranges, with counts of new, corrected, absent-in-newer and unchanged observations. Paginated detail exposes every changed date, older/newer values and signed difference in declared units (newer minus older); no percentage change.
- Use unrounded parsed values for equality. Blank and future omissions remain separate; absence from newer validated records is not proof of deletion or market-calendar completeness.
- English/Polish controls and diagnostics. Existing XLSX profiles remain available; they still contain settings rather than observations.

## Privacy and boundaries

Both workbooks and comparison results remain in tab memory. This feature adds no upload, automatic storage, cloud synchronization, database write or merge. It does not automatically install instruments: analysis of the newer workbook still requires validation and the separate Add action. Comparison export and CSV comparison are unsupported. Private worksheet/header names and instrument titles retain their supplied text in either interface language.

Six built-in instruments and the example workbook remain invented, with fixed sample cutoff 2026-10-06. No market-data source, automatic collector, telemetry, analytical formula or SQLite import workflow is changed. Existing profile downloads can contain private names but no observations; keep them private. Reload clears private imports and comparison results.

Publication requires the full suite, Linux Python 3.10/3.12 checks, isolated installed-wheel verification, public-page build and generated-source verification. Actual execution and deployment results belong in [STATUS.md](https://github.com/eluyz/SeasonLens/blob/v0.1.3/STATUS.md); these requirements do not imply that every platform was tested. Physical phones, Safari, native PDF dialogs and Windows/macOS execution remain unverified.

Code and invented examples: MIT. Bundled SheetJS: Apache-2.0. Earlier release tags and assets remain unchanged.

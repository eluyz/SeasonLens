# SeasonLens 0.1.1

Experimental pilot release with English/Polish interfaces, guides and a complete invented-data test.

**Start with the [pilot instructions](https://eluyz.github.io/SeasonLens/pilot/).** Use the [live demo](https://eluyz.github.io/SeasonLens/) or extract the frozen browser ZIP and open `pilot/index.html`. No account or installation is needed to perform the tasks. GitHub feedback is optional, requires an account and creates a public issue.

## Changes

- Two English/Polski tiles, reversible dynamic labels, legends, explanations and import messages. Only the language preference is remembered; private names, observations and machine identifiers are preserved.
- Report text and HTML language follow the language selected when the report is built. Later interface changes do not rewrite the saved snapshot.
- Polish wheat/EUR-PLN walkthrough; both guide languages are included in the browser ZIP.
- Three pilot tasks: import the invented wheat/EUR-PLN workbook, compare seasonal prices and coverage, then export an HTML report. Includes expected results, missing-data interpretation and English/Polish feedback worksheets.
- Public pilot-feedback issue forms and installed-wheel checks for localization assets.

## Downloads

## Validation and boundaries

The release requires the full analytical/browser suite, Linux Python 3.10/3.12 checks, installed-wheel verification, public-page build and exact generated-file verification before tag/draft publication. Actual results are recorded in [STATUS.md](https://github.com/eluyz/SeasonLens/blob/v0.1.1/STATUS.md).

No analytical formula changed in this release. Six built-in samples and the workbook are invented; no real market observations, automatic collection, telemetry, user accounts or hosted private database were added. Browser imports remain in tab memory and clear on reload. Public feedback must not include private data or reports. Visit/download counts do not establish independent adoption or completed analyses.

The sample cutoff remains 2026-10-06. Short imported histories retain absent months/years and insufficient-statistic messages. This is descriptive benchmark analysis, not an investable futures strategy. Physical phones, Safari and Windows/macOS execution remain unverified; PDF saving depends on the browser, and script-free HTML is the portable export fallback.

Code and invented examples: MIT. Bundled SheetJS: Apache-2.0. The original v0.1.0 tag and assets remain unchanged.

# SeasonLens 0.1.0

First public experimental release: explore your price history privately, inspect seasonal and market context, and keep a selected analysis report.

**Start in your browser:** [live demo](https://eluyz.github.io/SeasonLens/) · [wheat + EUR/PLN walkthrough](https://eluyz.github.io/SeasonLens/walkthrough.html). No account or installation is required. Every built-in observation and workbook example is invented.

## Included

- Six invented instruments: wheat, corn, rapeseed, EUR/PLN, EUR/USD and USD/PLN. Nine original/converted views.
- Browser CSV/XLSX preview with explicit dates, columns, units and roles; atomic validation and separate Add action. Private observations stay in current-tab memory.
- Exact-date same-workbook wheat/currency conversion, visible coverage and original-source isolation.
- Monthly averages, current-inclusive five-year comparison, separate equal-year seasonal profiles and six-line technical analysis.
- Historical changes/percentiles, market comparisons, volatility, RSI, correlations, benchmark scenarios and commodity/FX attribution.
- Historical buyer/seller VaR and Expected Shortfall, stress episodes, completed-year seasonal stability, fixed-baseline walk-forward evaluation and separate fundamental release vintages.
- Fixed report preview with selected charts, settings, legends and methods; script-free HTML download and browser-controlled PDF printing.
- Start here guide, invented XLSX template, narrow-screen local chart/table scrolling and keyboard navigation.
- Optional Python CSV import, auditable private SQLite updates/backups and direct ECB reference-rate updater.

## Downloads

- `seasonlens-browser-v0.1.0.zip`: frozen offline browser demo, workbook and tutorial. Extract and open `index.html`.
- `seasonlens-0.1.0-py3-none-any.whl`: installable Python package. Follow [installation](https://github.com/eluyz/SeasonLens/blob/v0.1.0/docs/INSTALLATION.md).
- `seasonlens-0.1.0.tar.gz`: Python source distribution with examples, documentation and tests.

GitHub also provides the complete tagged repository as source ZIP/tar archives. This release does not publish a package to PyPI.

## Validation and limitations

The analytical/browser-module suite, isolated wheel installation and public-demo build are required before publication. Actual verification is recorded in [STATUS.md](https://github.com/eluyz/SeasonLens/blob/v0.1.0/STATUS.md), with methods in [SCIENCE_SPEC.md](https://github.com/eluyz/SeasonLens/blob/v0.1.0/docs/SCIENCE_SPEC.md) and [METHODS.md](https://github.com/eluyz/SeasonLens/blob/v0.1.0/docs/METHODS.md).

This is historical benchmark analysis, not an executable futures strategy or guaranteed forecast. Counts measure observations, not certified sessions. No futures roll adjustment is supplied. There is no live futures feed, hosted private database or enabled nightly job. Physical phones, Safari and Windows/macOS execution remain unverified. Browser PDF saving and pagination depend on the browser; HTML remains the portable fallback. Version 0.1 does not promise a stable Python API.

Code and invented samples are MIT licensed. The bundled SheetJS reader is Apache-2.0 licensed. Importing data does not grant redistribution rights; sharing a report shares its visible results and declared provenance.

Report reproducible problems through [GitHub Issues](https://github.com/eluyz/SeasonLens/issues), using invented examples and the version/browser information. Do not attach restricted market or company files.

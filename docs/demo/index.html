SeasonLens 0.1.3 · practical demonstration

What changed in the new price list?

A new spreadsheet arrives. Before using it in a purchasing report, check whether it adds a quote, corrects history or omits a date. This example makes each difference visible.

Both files contain invented wheat prices. They are not exchange quotes, forecasts or a trading calendar. No account or installation is needed.

Open app in another tabDownload newer XLSXDownload older XLSX

Allow about three minutes to present the prepared example after downloading the files. A first independent attempt or phone import may take longer. Keep this guide beside the app. This is a presentation plan, not a measured completion-time claim.

1. Open the newer file · 0:00–1:00

  1. Start with a fresh app tab containing six sample instruments. Expand Start here and choose Open private import.
  2. Select seasonlens-newer.xlsx as the normal Excel workbook or CSV file. Set Analysis cutoff to 2026-10-07, then choose Open and preview file.
  3. Check the settings below. Select only column B, title Wheat sample, units EUR/t, role Wheat. Leave blank-skipping and cached-formula permissions unchecked.

Row 2 declares synthetic units. Amber row 3 is a deliberately invented live quote of 999 on October 8. Starting at row 4 excludes it by row selection; it is not counted as a future-row omission. Both workbooks have 210 historical observations and no formulas.

2. Compare before importing · 1:00–2:00

Under Compare two Excel versions, select seasonlens-older.xlsx as the Older Excel workbook, then choose Compare with older workbook. Do not reverse the files.

Expected result: 1 new · 1 corrected · 1 absent in newer · 208 unchanged.
Older: 210 observations, 2025-12-17–2026-10-06.
Newer: 210 observations, 2025-12-18–2026-10-07.
No skipped blank or future rows.

Difference means newer minus older in EUR/t, not percent. “Absent” describes these validated files only; it does not prove a quote was deleted. The comparison adds nothing: six built-in instruments should remain.

Suggested narration: “The latest file has a new day, but it also changes yesterday's price and no longer includes the first date. I can check those changes before using the file.”

3. Analyze the newer history · 2:00–3:00

  1. Choose Validate selected instruments. Confirm one instrument and 210 observations. Then choose Add validated instruments to this tab. There should now be seven instruments: six samples plus your import.
  2. In Analysis options, choose Wheat sample · private Excel in EUR/t. The last observation should be 215 EUR/t on 2026-10-07.
  3. Use View monthly averages. Read the reference date, units and coverage. The Monthly average prices table rounds commodity prices to whole units; the comparison above preserves the correction's precision.

Suggested narration: “Now I analyze the newer file explicitly. Missing months remain gaps. The selected five-year view does not turn this short example into five years of history.”

The example covers only December 2025–October 2026. It cannot establish reliable seasonality or a predictive advantage. If a result differs, check the file order, cutoff, selected column, row settings and whether a prior import is still in the tab.

Optional: keep a report

Choose Open report builder, select the monthly-price section, choose Build report preview and Download HTML. Check Wheat sample, EUR/t and 2026-10-07 in the report. This saves selected analysis results; it does not export the workbook comparison. Browser PDF printing is optional.

Both input files and comparison results stay in current-tab memory, without a data upload or automatic database write. Reload clears imports and comparisons. Downloads may contain private results when you use your own files. Visiting the app still uses GitHub Pages hosting.
